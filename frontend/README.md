# SenseGate-frontend
This repository contains the frontend code for the SenseGate MERN stack application. 

## Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **HTTP Client**: Axios / Fetch API

---

## Folder Structure

```
frontend/
├── public/             # Static assets like index.html
├── src/
│   ├── App.css         # Custom CSS or Tailwind configurations
│   ├── index.css        
│   ├── App.js          # Main App component
│   ├── index.js        # Entry point for React
├── package.json        # Dependencies and scripts
├── package-lock.json
└── README.md           # Documentation
```

---
## Installation and Setup

1. **Clone the repository**
   ```bash
   git clone 'https://github.com/sidd-phoenix/SenseGate-frontend.git'
   cd SenseGate-frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

   The application will run on `http://localhost:3000` by default.

---

## Usage

- Open the browser and navigate to `http://localhost:3000`.
- Explore the various features by interacting with the UI.
- The frontend communicates with the backend for real-time data.
