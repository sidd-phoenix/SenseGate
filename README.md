# 🚀 SenseGate

Smart IoT-based monitoring & access control system built using ESP32.

---

## ✨ Features

- Sensor-based trigger detection  
- WiFi-enabled communication  
- Real-time event monitoring  
- Modular & scalable design  

---

## 🏗 Hardware

- ESP32 Dev Module  
- Magnetic Reed Switch  
- LED / Buzzer  
- Resistors & Jumper Wires

## ⚙️ Setup

```bash
git clone git@github.com:sidd-phoenix/SenseGate.git
cd SenseGate
```

1. Open in Arduino IDE / PlatformIO  
2. Select **ESP32 Dev Module**  
3. Add your WiFi credentials  
4. Upload firmware
